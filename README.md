# Mast5112-ice-3

A React Native (Expo) app that lets the chef add menu items and view all items added.

## Features
- Clear application title
- Add screen: Dish Name, Description, Course (Picker) and Price
- Input validation with alerts (empty fields, invalid price)
- Menu screen: scrollabl#e FlatList of all items, updated automatically when an item is added
- Add multiple items

Editing, deleting, search, filter and statistics are planned for the Final PoE.

## React Native components used
| Requirement | Component |
|---|---|
| Titles and labels | Text |
| Dish name, description, price | TextInput |
| Course selection | Picker |
| Save / Cancel / Add buttons | Button |
| Display menu items | FlatList |
